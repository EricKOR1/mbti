# 64 성격 키

HEXACO 6요인 모델(정직-겸손 H, 정서성 E, 외향성 X, 원만성 A, 성실성 C, 개방성 O)로 성격을 측정하고,
각 요인의 높음/낮음 조합(2⁶ = 64)을 MBTI식 코드로 보여 주는 검사입니다. `index.html`을 브라우저로 열면 됩니다.

| HEXACO 요인 | 코드 글자 (높음 / 낮음) |
|---|---|
| 외향성 X | E / I |
| 개방성 O | N / S |
| 원만성 A | F / T |
| 성실성 C | J / P |
| 정서성 E | T(신중) / A(자기확신) |
| 정직-겸손 H | H(겸손) / B(대담) |

- 60문항(요인별 10문항, 정·역문항 반반), 7점 척도, 문항은 자체 작성
- 결과: 코드(예: `ENFP-T-H`), 요인별 0~100 점수와 해석, 경계선 표시, 강점/약점/직업/궁합
- 진행 상황 자동 저장, 키보드(1~7) 지원, 다크 모드
